# Package Description

This is a prisma package.

You can find prisma schema here: prisma/schema.prisma

# Package Structure

- src/browser.ts - This contains browser prisma enums, models and browser exports from prisma client generated folder.
- src/client.ts - This contains prisma client generated client folder.
- src/seed.ts - This contains seed script.
